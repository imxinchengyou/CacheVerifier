# Security Policy

This repository holds research code and experimental artifacts, not a
deployed service — the hosted product it documents is
[cacheverifier.com](https://www.cacheverifier.com).

If you find a security issue in the code here (e.g. in `cacheverifier/`
or `scripts/`), please report it privately via
[GitHub's private vulnerability reporting](https://github.com/imxinchengyou/CacheVerifier/security/advisories/new)
rather than opening a public issue. For issues affecting the hosted
service itself, use the same channel or contact
imxinchengyou@gmail.com directly.
